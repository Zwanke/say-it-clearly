# 帮我说清楚 · say-it-clearly

不知道怎么向 AI 描述需求？先随便说一句，让 AI 陪你慢慢说清楚。

这个 Skill 面向刚接触 AI 的人：用白话，一次只问一个问题；答不上来就给例子；信息够用就停，最后整理成一段可以直接发给 AI 的需求。

## 复制给 Agent，一句话安装

把下面整段发给支持安装技能的 Agent（例如 Codex）：

```text
请从这个 GitHub 仓库下载并安装 say-it-clearly 技能：
https://github.com/zealwander1014-crypto/say-it-clearly

请先阅读 README.md 和根目录的 SKILL.md，再安装到你当前使用的 Agent 支持的全局技能目录，让我以后在其他会话中也能使用。
技能位于仓库根目录，安装后的文件夹名称应为 say-it-clearly。
如果已经安装，请先比较内容，不要直接覆盖我的修改。
安装完成后，检查文件是否完整，并告诉我如何调用。
如果当前环境不支持安装 Skill，请明确说明。
```

Agent 需要能访问 GitHub、读写技能目录，并支持 Skill。普通聊天窗口不一定能自动安装。

## 下载 ZIP，手动安装

1. 在仓库页面点击 **Code → Download ZIP**。
2. 解压，将包含 `SKILL.md` 的文件夹重命名为 `say-it-clearly`。
3. 将整个文件夹放入 Agent 的技能目录。Codex 常见默认目录是 Windows 的 `%USERPROFILE%\.codex\skills`，或 macOS / Linux 的 `~/.codex/skills`；设置了自定义目录时使用实际目录。
4. 确认目录结构为 `skills/say-it-clearly/SKILL.md`，不要多嵌套一层。
5. 在新会话中试用；如果尚未识别，重启 Agent 后再试。

也可以先下载 [SKILL.md](./SKILL.md)，把正文发给 AI，请它按照这些规则与你聊天。这是直接使用说明，不等于全局安装。

## 怎么调用

在 Codex 中输入：

```text
用 $say-it-clearly 帮我说清需求：我想用 AI 帮我做点事情，但不知道从哪里开始。
```

其他 Agent 的调用语法可能不同，可以直接说“请使用 say-it-clearly 帮我说清需求”。

## 聊起来是什么样

**你：** 帮我写个东西。

**AI：** 这段东西准备拿来做什么？比如发给客户、发朋友圈，或者交给老师。

**你：** 发顾客群，通知明天上午停电，下午两点开门。

**AI：** 把下面这段发给 AI 就可以：

> 帮我写一条发到顾客群的通知：店里明天上午因停电暂停营业，下午两点恢复营业。写得简短、客气，让顾客一眼看清时间，提醒大家别白跑一趟。
